# Estructura de Buckets S3

Este documento describe la estructura de los buckets S3 utilizados en la plataforma VOD.

- **/raw**: Almacena los videos originales subidos por los usuarios.
- **/processed**: Almacena los videos procesados en múltiples resoluciones (HLS/DASH).
- **/thumbnails**: Almacena las miniaturas generadas para cada video.
- **/subtitles**: Almacena los archivos de subtítulos (SRT/VTT).
